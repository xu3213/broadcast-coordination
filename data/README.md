# Data

All experimental data is generated programmatically by the simulation framework. No external datasets are required to reproduce the core results (Results 1, 2, and 3).

## Real-parameter validation (Result 4, optional)

Result 4 includes an optional experiment that uses real household battery parameters from the NextGen project (ACT, Australia).

**Dataset:** Sturmberg, B. & Shaw, M. (2025). Select data from the NextGen energy storage trial in the ACT, Australia. Zenodo. https://doi.org/10.5281/zenodo.14885589

To run the real-parameter validation, download the CSV files and place them in:

    data/nextgen/

If the data is not available, the validation step is skipped automatically.
